# HTML-Class-Assignment

Resident Raver

Resident Raver is a 2D action-platformer made with ImpactJS. You play as a character exploring the first level (dorm1) while fighting zombies. A basic level editor (Weltmeister) is included so you can create and test levels later.


How to Play

Move: LEFT / RIGHT

Jump: X

First level: Dorm1

Open index.html in a browser to launch the game.



Project Structure

index.html → Starts the game

lib/game/main.js → Game logic and controls

weltmeister/ → Minimal level editor

media/ → Fonts, images, sprites





Features

Simple 2D zombie action

Basic level editor included

Canvas-based gameplay with 320×240 resolution

Extendable: add your own enemies, levels, and UI




Next Steps

Add your own graphics, sounds, and animations

Expand the levels and enemies

Make the game ready for web or desktop
